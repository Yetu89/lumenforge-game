LUMENFORGE — Keeper of the Last Light: a roguelite eclipse-beam game. Rotate the lens ring, sweep your aim over golden motes to charge alignment, and fire the Eclipse Beam across 3 nights of 5 waves each against 8 enemies and 3 bosses, with 16 relics, synergies, and a workshop of permanent upgrades.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
